命令复习笔记

说明：按功能分类整理，命令来自三次 shell 命令行会话。
会话一：fd/7z/awk/tar 批量处理与管道传参；会话二：zellij、用户组、fish/tide、显示解码、内核、nvim；会话三：磁盘占用排查。

一、Shell 基础与脚本

1. 基础语法

  • ;：无条件执行下一条；&&：前一条成功才执行。
  • |：管道，前一个命令的 stdout 喂给后一个命令的 stdin。管道传的是数据流，不是文件名。
  • <（单箭头）：文件内容重定向进 stdin；<<（双箭头 heredoc）：多行文本到结束符。
  • "" 内 $变量、$(...) 会被解析；'' 内原样保留。

2. sh -c 传参（重点）

sh -c '脚本' 参0 参1 参2... —— 脚本字符串后的参数依次进 $0、$1、$2…

  • $0 按惯例放”程序名”，占位用，可写 sh；
  • 真实参数从 $1 开始（和普通脚本一致）。

sh -c '脚本' A B C 等价于一个名为 A 的脚本带参数 B C，只是省了临时文件。

在 fd -x 里想用管道，把整段包进 sh -c '...' 即可；引号太多就写成独立脚本文件再调用。

3. 后台并行（for + & + wait）

  • &：把每条命令丢到后台并行跑；
  • wait：等所有后台任务结束；
  • 2>/dev/null：丢权限报错，只看得到结果；
  • 注意 for 循环体里的变量要带引号 "$d"（防路径带空格）。

二、文件查找与批处理

1. fd 批量执行

命令 含义
fd . . 模式是第一个 .（正则匹配所有），目录是第二个 .（当前目录，可省略）
fd -x CMD {} 对每个搜索结果并行执行 CMD（小写 x）
fd -X CMD {} 把所有结果一次性作为参数执行 CMD（大写 X，仅一次）
-t f / -e tar 只匹配文件 / 扩展名是 .tar
--exclude file 排除某个文件（防自己扫到自己）

fd 没有内置”逐条顺序执行”模式。要顺序执行用 while read 循环：
while read -r f; do 7z x -y "$f"; done < <(fd . -t f -e tar)
或 find . -name '*.tar' -exec 7z x {} \;

2. find 查找

参数 含义
/ 起点目录（可换 /home 等）
-xdev 不跨文件系统（同 du 的 -x），避免扫进其他挂载盘
-size +500M 大于 500M 的文件（-500M 小于，500M 精确）
-exec ls -lh {} \; 对每个结果执行 ls 看大小；{} 是结果占位符，\; 结尾
2>/dev/null 丢掉无权限目录的报错

比 du 快得多：du 要遍历所有文件统计大小，find 直接按 size 元数据筛。

3. tar 文件传输（通过 adb）

cat 只能传单个文件内容（丢名字）；tar 保留名字+权限+内容；adb push 的文件名走了独立编码通道最容易坏。

四、磁盘与存储

1. 磁盘状态查看（df）

命令 含义
df -h 看各分区使用率（-h 人类可读）；还显示每个挂载点各自占用，/var、/home 若在同一分区会重复列出
df -i 看 inode 使用率（文件数爆满时用，空间剩很多但报”磁盘满”就是 inode 满了）

关键认知：/var/log、/var/cache、/home 可能都挂在同一块根分区上，清理时按总占用算，别被单目录的”使用率 78%”误导。

2. 目录大小扫描（du）

命令 含义
du -sh 目录 只看该目录总大小（-s 汇总、-h 人类可读）
du -sh 目录1 目录2 一次查多个目录，各自独立输出
du -hxd1 / 看根下第一级各目录大小；d1=深度 1，x=不跨文件系统（跳过 /dev、/proc 等挂载点），h=人类可读
du -hxd1 /home | sort -rh | head -20 按大小降序取前 20：sort -rh（r=反序，h=按人类可读单位 1G>900M 正确比较）
du -xh --max-depth=2 目录 看两层的更细分布（深了会很慢）

坑：du 对文件极多的目录（如 /home 下塞满大量小文件）会卡死超时。先 d1 粗扫锁定嫌疑，再逐层深入；不要一上来全盘 du -xhd1 /。

六、终端会话管理（zellij）

命令 含义
zellij 进入新会话（关掉会问是否销毁）
zellij -s 名字 命名会话
zellij attach 重连最近会话
zellij ls 列出所有会话
zellij kill-session 名字 杀掉指定会话（在外面操作）
zellij kill-all-sessions 杀掉所有会话
pkill zellij 进程僵死时强杀

常用快捷键：Ctrl+p 切面板、Ctrl+t 切标签、Ctrl+n 新面板、Ctrl+d 关闭面板、Ctrl+s 会话管理界面、Ctrl+g 帮助总览。
zellij 和 tmux 一样支持持久会话：关掉窗口后进程还在后台跑，zellij attach 重连。Ghostty 本身则没有内置 detach/持久会话，要放后台必须靠 tmux/zellij。

七、桌面显示与解码

坑：kimageformats 装了、kimg_avif.so 插件也在（/usr/lib/qt6/plugins/imageformats/），但打开 AVIF 仍失败 —— 因为该插件依赖的 libavif.so.16 没装（Arch 把它当运行时可选依赖）。用 ldd /usr/lib/qt6/plugins/imageformats/kimg_avif.so 可确认。
Dolphin 远程目录（SMB/SSH）默认不生成缩略图：Dolphin → 设置 → 通用 → 预览 → 勾选 “Show previews for remote files”。

查看快捷键：:map（全部）、:nmap/:imap/:vmap（按模式）、:verbose map <键>（看来源文件）。

十、常见坑与经验

命令执行类

  1. fd -x 并行 + 7z x 的 \r 进度 → 进度行互相覆盖、看不到输出，但文件在解。加 -y -bb1 或改顺序执行。
  2. 重定向目标被自己扫到：>> filelist.txt 在当前目录，fd 会把 filelist.txt 也传给 7z → 加 --exclude 或输出到 /tmp。
  3. 非 tty 时输出是块缓冲：被 Ctrl-C 杀掉会丢输出，文件其实已创建。

排查方法论

  1. 先粗后细：df -h 看整体 → du -d1 逐级缩小范围 → 再深挖。别一上来全盘扫。
  2. du 会卡死的场景：小文件海量（node_modules、.cache 之类），此时改用 find -size 或按文件数定位。
  3. 权限错误直接丢：扫描类命令统一加 2>/dev/null，否则满屏 Permission denied 淹掉结果。
  4. 排查记录要留档：写进 md 文档，记下每步命令、结果、结论，方便下次接着查。
