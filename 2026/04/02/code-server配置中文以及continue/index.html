code-server配置中文以及contine

发表于2026-04-02|更新于2026-08-15
|总字数:989|阅读时长:4分钟|浏览量:|评论数:

很久之前就为code-erver没法设置中文而困扰，这次终于在网上搜到怎么解决了，可得赶紧记录下来防止以后忘记。

安装code-server

要下载的是code-server而不是openvscode-srever,后者是开源版本

安装完成后，有两个服务被创建，分别是/usr/lib/systemd/system/code-server@.service和/usr/lib/systemd/user/code-server.service，前者是以系统级服务运行，可以为所有用户提供服务，后者是以用户级服务运行，仅在特定用户的上下文中运行，我使用后者

默认的配置文件位置在~/.config/code-server/config.yaml,可以按需修改

配置中文

先按一般vscode来安装中文扩展，这时候发现不管怎么重启界面都不会变成中文

以下内容摘自Vscode/Code-Server 安装中文包——CI/CD

看样子是因为languagepacks.json没有正确生成，直接使用大佬的脚本可以直接解决

配置contine插件

因为没有https没法用这个插件，所以最好还是做一个证书。

这会生成 localhost+2.pem 和 localhost+2-key.pem 两个文件,编辑你的 code-server 配置文件

然后重新启动code-sercer

把cert复制到你客户端的机器上，windows的话需要修改后缀为crt，双击证书，给本地计算机安装，选择受信任的根证书颁发机构
